# 生产力工具技能集合

面向文件生成与自动化任务的技能集合，按「专用技能分支」的方式组织：每个技能独立成目录，统一索引在 `skills/SKILL.md`。

## 覆盖方向

- 自动创建系统文件与文档
- 批量处理与自动化工作流
- 模板驱动的内容生成

## 目录结构

```
.
├── skills/
│   └── SKILL.md   # 技能集合索引与扩展规范
└── LICENSE        # MIT
```

当前仓库包含集合索引与扩展规范；新增技能按下面的约定扩展，不需要改动索引之外的结构。

## 新增一个技能

1. 在 `skills/` 下创建新文件夹（建议用技能名，小写连字符）
2. 编写该文件夹的 `SKILL.md`，至少包含名称、描述、适用场景、使用方式
3. 实现功能代码或脚本
4. 更新 `skills/SKILL.md` 索引

## 使用方式

将整个目录作为 skills 根目录加载，或只取需要的子目录放入 Agent 的 skills 目录。
